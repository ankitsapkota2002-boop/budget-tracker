# Budget Tracker (Flutter)

A mobile budget tracking application built with Flutter.

## About

This project is a student / junior developer portfolio piece focused on mobile app development using Flutter.  
It aims to help users track income, expenses, and manage personal budgets in a clean and simple interface.

> Note: This repository is currently being developed. Core features and code will be added as the project progresses.

## Planned Features

- Add income and expense transactions
- Category-based tracking
- Simple dashboard / overview
- Clean and modern UI
- Cross-platform (Android & iOS)

## Tech Stack

- Flutter
- Dart

## Getting Started

```bash
git clone https://github.com/ankitsapkota2002-boop/budget-tracker.git
cd budget-tracker
flutter pub get
flutter run
```
